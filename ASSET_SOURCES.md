# Asset sourcing checklist

Use only assets whose license clearly allows commercial game use.

Suggested sources:
- Kenney — excellent for UI, simple 3D kits, particles, audio. Many packs are CC0.
- Quaternius — stylized low-poly 3D packs, often CC0 or permissive; verify the specific pack/license.
- Poly Pizza — useful low-poly search; filter by license and verify each model.
- ambientCG — CC0 materials/textures if needed.

Needed replacements:
- Toy-like cannon
- 3–5 wood block shapes
- 3–5 stone block shapes
- 3–5 ice block shapes
- Ball
- Tray/platform variants
- Clouds / trees / rocks / distant background props
- Wood / stone / ice impact VFX
- Shot trail / muzzle flash
- Confetti / star VFX
- UI button/icon set
- 20–30 impact/UI/win/lose sounds
